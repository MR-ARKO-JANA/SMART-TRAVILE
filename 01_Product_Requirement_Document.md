# Smart Travel Insights — Product Requirement Document (PRD)

## 1. Project Overview
Smart Travel Insights is a full-stack React JS travel application that helps users plan journeys, discover destinations, manage trips and budgets, receive travel alerts, and optionally contribute consent-based travel data for transportation research and planning.

## 2. Problem Statement
Traditional transportation surveys depend heavily on manual forms and delayed data collection. This makes large-scale, real-time travel analysis difficult. At the same time, travellers often use multiple apps for navigation, trip planning, alerts, budgets and saved destinations.

## 3. Product Goal
Build one user-friendly platform that:
- Helps travellers plan and manage journeys.
- Provides useful travel recommendations.
- Collects trip information only with user consent.
- Provides emergency/SOS support.
- Gives planners/researchers aggregated insights through a dashboard.

## 4. Target Users
### Traveller
Plans trips, saves destinations, records journeys, manages budget and receives alerts.

### Research/Planning User
Views aggregated travel trends, trip chains, seasonal patterns and reports.

### Administrator
Manages users, destinations, alerts and system-level information.

## 7. Functional Requirements
- Users can create and manage trips.
- Users can add destinations to a bucket list.
- Users can record travel mode, origin, destination and approximate trip information.
- Users must explicitly opt in before research data sharing.
- Users can change consent settings at any time.
- The system can display routes on a map.
- The dashboard can display aggregated travel statistics.
- Emergency actions can show available emergency contacts/support.

## 8. Non-Functional Requirements
- Responsive design
- Secure authentication
- Fast API responses
- Privacy-first data collection
- Scalable backend
- Clean component architecture
- Input validation
- Error handling

## 9. Success Criteria for PBL Review
For the first review, a realistic target is 50–60% completion:
- React project runs successfully.
- Main UI pages are implemented.
- Navigation works.
- Trip planning flow works.
- Forms have validation.
- Backend/API integration is partially or fully connected.
- Database structure is prepared.
- Remaining work is clearly documented.

## 10. Important Privacy Rule
Research data collection must be consent-based. The user should understand what information is collected, why it is collected and whether it can be withdrawn.
